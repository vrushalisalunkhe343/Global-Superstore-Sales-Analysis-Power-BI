# Global-Superstore-Sales-Analysis-Power-BI
Interactive Power BI dashboard for analyzing Global Superstore sales data, including sales, profit, category, sub-category, regional performance, quantity, and discount insights.

An interactive Power BI dashboard developed using the Global Superstore dataset to analyze sales performance and generate meaningful business insights.

## Key Analysis

- Sales and Profit Analysis
- Category and Sub-Category Performance
- Regional Sales Analysis
- Quantity and Discount Analysis
- Interactive Filters and Visualizations

## Tools & Technologies

- Power BI
- DAX
- Data Visualization
- Excel

## Dashboard

The dashboard provides an interactive view of key sales and business performance metrics.

## Project Objective

The objective of this project is to analyze Global Superstore sales data and identify trends and patterns across different categories, regions, products, and business metrics.
